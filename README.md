# Pantip Sentiment Analysis

โครงงานวิเคราะห์ความรู้สึกจากความคิดเห็นภาษาไทยด้วย Next.js, React, Tailwind CSS และ FastAPI บน Python 3.11 ระบบจำแนกข้อความเป็น `positive` (เชิงบวก), `negative` (เชิงลบ) และ `neutral` (เป็นกลาง) การฝึกและทำนายทำงานในเครื่อง

## เริ่มใช้งานบน Windows

ใช้ PowerShell สองหน้าต่างและเปิด [Pantip Sentiment](http://127.0.0.1:3000) หน้าเว็บเรียก FastAPI ผ่าน Next.js ทั้งสองบริการฟังเฉพาะบนเครื่องนี้

**หน้าต่างที่ 1 · Python API**

```powershell
Set-Location 'C:\Users\Unknown\Desktop\pantip-sentiment-analysis'
.\.venv\Scripts\python.exe -m uvicorn api:app --host 127.0.0.1 --port 8000
```

**หน้าต่างที่ 2 · เว็บ**

```powershell
Set-Location 'C:\Users\Unknown\Desktop\pantip-sentiment-analysis\frontend'
npm.cmd ci
npm.cmd run build
npm.cmd start
```

เมื่อมี production build แล้ว เปิดครั้งถัดไปด้วย `npm.cmd start` ในโฟลเดอร์ `frontend` ได้เลย ใช้ Ctrl+C ในแต่ละหน้าต่างเพื่อปิดบริการ ระหว่างพัฒนาใช้ `npm.cmd run dev`

สำหรับเครื่องใหม่ ติดตั้ง Python 3.11 และ Node.js 22.12 ขึ้นไป จากโฟลเดอร์โครงการรัน `py -3.11 -m venv .venv` และ `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` ก่อนเปิดบริการ ใช้โมเดลที่บันทึกใน `models/sentiment_model.pkl` ได้ทันที หากต้องการฝึกจาก CLI ใช้ `.\.venv\Scripts\python.exe train.py` ส่วนหน้า Streamlit เดิมเปิดด้วย `.\.venv\Scripts\python.exe -m streamlit run app.py`

## สาธิตหน้าชั้นเรียน

1. เปิด **วิเคราะห์ความคิดเห็น** เลือก **ข้อมูลสาธิต** แล้วกด **โหลดข้อมูลสาธิต** จะเห็นชื่อไฟล์ จำนวนความคิดเห็น และตัวอย่างข้อความ
2. กด **วิเคราะห์ความคิดเห็น** เพื่อเปิด HUD มีแถบเตรียมข้อมูลด้านซ้าย สมองโฮโลแกรมหมุนตรงกลาง และแถบจำแนกด้านขวา ตัวนับเพิ่มตามจำนวนที่ทำนายสำเร็จ จออาจผ่านไปเร็วเมื่อมีข้อมูลน้อย
3. ระบบจะเปิด **ผลการวิเคราะห์** อัตโนมัติ ตรวจสอบแผนภูมิ จำนวน เปอร์เซ็นต์ และตาราง แล้วกด **ดาวน์โหลดผลทั้งหมด CSV**
4. เปิด **ฝึกโมเดล** เพื่อดูผลเปรียบเทียบ Cross-validation คะแนนชุดทดสอบ และตารางสับสน

ภาพสมองใช้ React Three Fiber หมุนโมเดล GLB ที่สร้างสำหรับโครงการรอบแกนตั้งตามเวลาระหว่างเฟรม เมื่อปิดการเคลื่อนไหวหรือตัวแสดง WebGL ใช้งานไม่ได้ ระบบแสดงภาพนิ่งในเครื่อง [ที่มาและใบอนุญาต GLB](frontend/public/brain-LICENSE.txt)

หน้าเว็บและกราฟภาษาไทยใช้ LINE Seed Sans TH ของ LY Corporation จากไฟล์ในเครื่อง ดูเงื่อนไข SIL Open Font License 1.1 ใน [ใบอนุญาตฟอนต์](assets/fonts/OFL.txt) และ [เว็บไซต์ LINE Seed](https://seed.line.me/index_th.html)

## แหล่งความคิดเห็นและรูปแบบ CSV

- **Pantip** รับลิงก์ HTTPS รูปแบบ `https://pantip.com/topic/12345678` หรือโฮสต์ `www.pantip.com` สำหรับกระทู้สาธารณะที่ได้รับอนุญาต ตรวจสอบ `robots.txt` ก่อนขอข้อมูล หากไม่มีความคิดเห็นใน HTML ระบบจะอ่านความคิดเห็นหลักหน้าที่ 1 จากช่องทางสาธารณะที่หน้า Pantip ใช้โหลดความคิดเห็น จำนวนอาจไม่ครบทั้งกระทู้ หากเข้าถึงไม่ได้ให้ใช้ CSV [กฎและกติกาของ Pantip](https://pantip.com/about/tos)
- **CSV ที่อัปโหลด** ใช้หัวตาราง `comment_text` รองรับ UTF-8 และ UTF-8-SIG ระบบจะข้ามแถวว่างและแจ้งจำนวนที่ข้าม โดยรักษาข้อความเดิมและลำดับ
- **ชุดสาธิต** คือข้อความภาษาไทยที่เขียนขึ้นสำหรับโครงงานใน `data/pantip_comments.csv` มี 42 ความคิดเห็น ใช้ทดลองทำนาย

```csv
comment_text
อาหารอร่อยมากค่ะ
"สั่งมาแล้ว, แต่ได้รับของไม่ครบ"
00123
```

ไฟล์ฝึกใช้ `text,label` รองรับสามป้ายกำกับข้างต้น ระบบปรับช่องว่างและ Unicode ก่อนตรวจข้อความซ้ำ แล้วรวมรายการซ้ำที่มีป้ายเหมือนกัน หากข้อความเดียวกันมีป้ายขัดแย้งกัน ระบบจะแจ้งให้แก้ไฟล์ก่อนฝึก ไฟล์ฝึกต้องมีตัวอย่างเพียงพอให้ทั้งชุดฝึก ชุดทดสอบ และการแบ่ง folds มีครบทั้งสามคลาส

```csv
text,label
บริการดีมาก,positive
ผิดหวังกับสินค้า,negative
ร้านเปิดเวลาเก้าโมง,neutral
```

ดาวน์โหลดได้เป็น UTF-8-SIG โดยมีหัวตาราง `comment_text,predicted_sentiment` เปิดไฟล์แบบนำเข้า CSV และตั้งคอลัมน์ความคิดเห็นเป็นข้อความหากต้องการรักษาเลขศูนย์นำหน้าใน Excel ตัวอย่างผลที่ทำนายจากโมเดลที่บันทึกมาอยู่ที่ `data/example_predictions.csv`

## ข้อมูลฝึกและขอบเขตคะแนน

ชุดฝึกเริ่มต้นมาจาก **Wisesight Sentiment Corpus v1.1** ข้อความจากสื่อสังคมออนไลน์ภาษาไทยเผยแพร่ภายใต้ **CC0 1.0** จึงใช้และแจกจ่ายชุดข้อมูลได้ ชื่อและเครื่องหมายการค้าที่ปรากฏในข้อความเป็นของเจ้าของเดิม [คลังข้อมูลและเงื่อนไข](https://github.com/PyThaiNLP/wisesight-sentiment/tree/v1.1)

แปลงไฟล์ `pos.txt`, `neg.txt` และ `neu.txt` เป็น `positive`, `negative` และ `neutral` ตามลำดับ ตัด `q.txt` ออกทั้งหมด และตัด 4 แถวจากข้อความ 2 แบบที่ป้ายกำกับขัดแย้งกันหลังปรับข้อความ ขั้นฝึกตัดรายการซ้ำภายในคลาสอีก 1 รายการ เหลือ 26,157 รายการ

| ป้ายกำกับ | จำนวนหลังตรวจสอบ |
| --- | ---: |
| เชิงบวก | 4,776 |
| เชิงลบ | 6,822 |
| เป็นกลาง | 14,559 |

คะแนนวัดการทำงานบนข้อความ Wisesight ที่กันไว้ การนำโมเดลไปใช้กับกระทู้ Pantip จริงอาจได้ผลต่างกันตามหัวข้อ ภาษาพูด และบริบท เช่น การประชดหรือการอ้างข้อความของผู้อื่น

## อ่านโค้ดและผลประเมิน

1. เริ่มที่ `train_and_save()` ใน `train.py` ฟังก์ชันนี้อ่านข้อมูล แบ่งฝึก/ทดสอบ 80/20 แบบรักษาสัดส่วน เปรียบเทียบ เลือก ฝึก ประเมิน และบันทึก
2. ดูตัวสร้าง Pipeline ตามลำดับ `build_naive_bayes_pipeline()`, `build_logistic_regression_pipeline()` และ `build_linear_svm_pipeline()` ทั้งสามใช้ `build_pipeline()` ร่วมกัน
3. ดู `preprocessing.py` ตัวตัดคำ `newmm` แบ่งข้อความไทยเป็นคำ แม้ไม่มีช่องว่าง โค้ดรักษาคำปฏิเสธและอีโมจิไว้โดยค่าเริ่มต้น TF-IDF แปลงคำเดี่ยวและคู่คำเป็นตัวเลข คำที่พบบ่อยในข้อความและพบน้อยในเอกสารอื่นมักได้น้ำหนักมาก
4. Cross-validation ใช้ folds ชุดเดียวกันสำหรับทุกตัวจำแนก โดยเรียนรู้คำศัพท์ใหม่ภายในแต่ละ fold ใช้ **Macro F1** ซึ่งเฉลี่ย F1 ทั้งสามคลาสโดยให้น้ำหนักเท่ากัน F1 รวม Precision และ Recall เมื่อคะแนนเท่ากันจะเลือกรุ่นที่อยู่ก่อนในลำดับข้างต้น
5. ตาม Pipeline ที่บันทึกไปยัง `load_model()` และ `predict_batches()` ใน `predict.py` ซึ่งใช้การเตรียมข้อความกับ TF-IDF ชุดเดียวกับตอนฝึกและคืนผลตามลำดับอินพุต

ในตารางสับสน แถวคือป้ายกำกับจริง คอลัมน์คือผลทำนาย ลำดับทั้งสองแกนคือ เชิงบวก เชิงลบ เป็นกลาง ตัวเลขบนเส้นทแยงมุมคือจำนวนที่ทำนายถูก

### ผล Cross-validation

ใช้ seed 42 แบ่งข้อมูลเป็นชุดฝึก 20,925 รายการและชุดทดสอบ 5,232 รายการ เปรียบเทียบบนชุดฝึกด้วย Stratified Cross-validation 5 folds

| ตัวจำแนก | Macro F1 เฉลี่ย | ส่วนเบี่ยงเบนมาตรฐาน |
| --- | ---: | ---: |
| Multinomial Naive Bayes | 0.4574 | 0.0066 |
| Logistic Regression | 0.6677 | 0.0071 |
| **Linear SVM** | **0.6715** | **0.0087** |

### ผล Linear SVM บนชุดทดสอบที่กันไว้

| Accuracy | Macro Precision | Macro Recall | Macro F1 |
| ---: | ---: | ---: | ---: |
| 0.7295 | 0.7011 | 0.6657 | 0.6766 |

| ป้ายกำกับ | Precision | Recall | F1 | จำนวนจริง |
| --- | ---: | ---: | ---: | ---: |
| เชิงบวก | 0.6361 | 0.4356 | 0.5171 | 955 |

ดูคะแนนเต็มและเมทริกซ์ใน `models/evaluation.json` หรือดูกราฟในเมนู **ฝึกโมเดล**
